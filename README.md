# 🌸 Nexus AI: Multilingual Code Decoder

A futuristic, high-performance AI tool that explains complex code logic across multiple programming languages. 

### 🚀 Features
* **Multilingual:** Supports Python, Java, JS, C++, and more.
* **Smart Fallback:** Cycles through multiple AI models if one is busy.
* **Cyberpunk UI:** Matrix-inspired theme with typewriter effects.

### 🛠️ Setup
1. Clone the repo: `git clone https://github.com/cj7-k/Nexus-AI.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Add your OpenRouter API Key to a `.env` file.
4. Run: `python app.py`
